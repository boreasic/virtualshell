Common questions

Where are my files?

Open VirtualShell’s Filesystems screen to manage Linux roots. Each root can appear as a location in the iOS Files app, where you can move files between apps.

How do I install packages?

Use apk add <package> in the terminal. VirtualShell configures a signed package snapshot. Alpine repositories are available when explicitly selected with @alpine. Installing packages needs a network connection.

How does location access work?

Location is optional. A guest command can read /dev/location; the first foreground read asks for iOS When In Use permission. An active reader can continue in the background with the iOS location indicator. Stop the command with Ctrl-C to close the reader.

Where are third-party notices?

Open Settings in VirtualShell and choose Third-Party Notices to read the bundled notices and licenses.
