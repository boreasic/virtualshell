# VirtualShell website

Static public pages for VirtualShell, hosted through GitHub Pages from this repository's `main` branch.

Live site: https://boreasic.github.io/virtualshell/

- `index.html` — product overview
- `support.html` — public support URL
- `privacy.html` — public privacy policy URL

No build tools or third-party scripts are required. Preview locally with `python3 -m http.server 8000`.
